LUIQ — установка на iPhone
1. Загрузите всю эту папку на любой бесплатный хостинг с https (GitHub Pages, Netlify, Cloudflare Pages).
2. Откройте адрес в Safari на iPhone.
3. Нажмите «Поделиться» -> «На экран Домой» -> «Добавить».
После этого LUIQ запускается с рабочего стола как приложение и работает без интернета.
